    Testing

    Run everything before you ship.

    npm run verify is the gate: it builds, then runs the core suite, the CLI end-to-end suite, the real desktop app under Electron, and the accessibility, responsive, performance and docs-site suites. Prefer it over picking one script, because a suite that only runs in CI is a suite that quietly rots.

    Packaging

    Produce installers.

    Packaging writes to release/. Those artifacts are what the download buttons on the site link to, so the file names here and the labels there must agree.

    Architecture

    Clean, layered design.

    The cryptographic core is UI-agnostic. The CLI and the Electron GUI are thin frontends over the same engine — which is why a vault written by one opens in the other.
